**[free-exercise-db](https://github.com/yuhonas/free-exercise-db)**

No attribution is legally required, but this file records where each image
came from for traceability, plus a note on any match that isn't exact
(equipment substituted, a combo/variant shown as its base movement, or a
bilateral image standing in for a unilateral exercise).

and the free-exercise-db `id` (its folder under `exercises/` in that repo,
